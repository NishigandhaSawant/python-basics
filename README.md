# Python Fundamentals & Basics

A comprehensive repository containing core Python concepts, fundamental syntax, and practice code scripts.

## 📂 Repository Structure

* **`introduction/`** - Python setup, basic syntax, and initial concepts
* **`operators/`** - Arithmetic, logical, assignment, and comparison operators
* **`control statements/`** - Conditional statements (`if-else`) and loops (`for`, `while`)
* **`strings/`** - String operations, formatting, and built-in methods
* **`List/`** - Operations, methods, and indexing with Python lists
* **`tuples/`** - Immutable sequence structures and tuple operations
* **`Dictionary/`** - Key-value pair manipulation and dictionary operations
* **`Functions.py`** - Function definitions, parameter passing, and return values
* **`OOP/`** - Object-Oriented Programming concepts (Classes, Objects, Inheritance)
* **`exception handling/`** - Error handling using `try`, `except`, and `finally`
